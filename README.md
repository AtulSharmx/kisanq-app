# KisanQ — Android app

Public download for the KisanQ farmer app. **This repository holds the APK and nothing else** —
no source code, no configuration, no data. The project source is private.

## Install

Download the latest `KisanQ.apk` from [Releases](../../releases/latest), or scan the QR on
[kisanq.web.app](https://kisanq.web.app).

KisanQ is not published on Google Play, so Android will ask you to allow the install the first
time. Open the downloaded file, allow installs from your browser, then confirm.

Requires Android 7.0 or newer.

## What it is

A working prototype of a mandi procurement queue: a farmer books a slot, follows their place in
the queue, and sees the weighing and quality figures recorded at the counter as they are
recorded.

**Never enter a real Aadhaar number.** Identity verification in this build is a demonstration —
any twelve digits work. Payments are simulated: stages advance, but no money moves and no bank
or payment system is connected.

KisanQ is an independent student project. It is not affiliated with or endorsed by any
government authority.
